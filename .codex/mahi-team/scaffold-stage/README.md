# Hindu Calendar - Panchang

Android first Expo app scaffold. See `HINDU_CALENDAR_CODEX_MASTER_PROMPT.md` and `docs/ARCHITECTURE.md` in the project root for the implementation contract.

Requires Node 22.13+ and npm. Run `npm ci`, then `npm start`. Use `npm run android` with an Android device or emulator. Run `npm run typecheck`, `npm run lint`, `npm run format:check`, and `npm test` before changes are handed off.

The app starts without an `.env` file. `eas.json` includes development, preview APK, and production AAB profiles. Build execution requires EAS credentials and is tracked separately.
